# Northstar Product Catalog

A responsive product catalog built with plain HTML, CSS, and JavaScript. It retrieves sample product data from the DummyJSON API.

## Features
- Fetches all products and category names from DummyJSON
- Search by product name, description, or brand
- Filter by category
- Sort by price, rating, or product name
- Product detail modal
- Pagination (12 products per page)
- Responsive layout for desktop and mobile
- Loading, empty, and error states

## Run locally
1. Extract the ZIP file.
2. Open the product-catalog folder.
3. Double-click index.html, or use VS Code with Live Server.
4. Make sure you have an internet connection.

## Important note
DummyJSON is a sample API. Product details, prices, ratings, and stock are demonstration data.
